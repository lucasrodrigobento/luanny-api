📡 QIVE (ex-Arquivei)

  • Base URL + API ID + API Key
  • CNPJs monitorados (por tenant)
  • GET /v1/nfe/received
  • Paginação automática (>50 NFes)

🏗️ UAU (Globaltec)

  • Base URL + Integration Token (JWE)
  • Login + Senha + Site por tenant
  • Auth em 2 níveis (JWE + sessão)
  • Cache token 30 min por tenant
